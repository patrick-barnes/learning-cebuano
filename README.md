# learning-cebuano

Learning Cebuano web app.

Published to: [https://pjbarnes.dev/learning-cebuano](pjbarnes.dev/learning-cebuano)

# local development

Use Node 22 (see `.nvmrc`):

- `nvm install 22.12.0`
- `nvm use 22.12.0`

Build:

- `npm install`

Run:

- `ng serve`

Test:

- `npm test` (runs unit tests directly via Vitest)

Publish:

- `publish.cmd` to update `docs/*`.
- Commit and push changes to `docs/*`.
- Monitor the [github-pages workflow](https://github.com/patrick-barnes/learning-cebuano/actions)
- Verify live site: Published to: [https://pjbarnes.dev/learning-cebuano](pjbarnes.dev/learning-cebuano)
